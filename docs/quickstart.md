# Quickstart

Install MLClient:

```sh
pip install mlclient
```

## Run a query

```python
from mlclient import MLClient

with MLClient() as ml:
    print(ml.eval.xquery('"Hello World!"'))  # Hello World!
```

The defaults connect to a local MarkLogic REST App Server at `http://localhost:8000`
with Digest authentication and `admin` / `admin` credentials. You need a running
server with those settings. The context manager closes connections on exit.

## Connect to another server

Pass only the settings you want to change:

```python
with MLClient(
    host="ml.example.com", username="my-user", password="my-password"
) as ml:
    print(ml.eval.xquery('"Hello World!"'))
```

Add `port=8100` for a different REST port or `protocol="https"` for HTTPS.
[Connection settings](user/python/connections.md) cover authentication and TLS;
[environments](user/environments.md) let you share configuration between Python and CLI.

## Work with documents

Create a document, write it and read its content back:

```python
from mlclient import MLClient
from mlclient.models import Document

with MLClient() as ml:
    document = Document.create("/hello.json", {"message": "Hello, MarkLogic!"})
    ml.documents.write(document)
    document = ml.documents.read("/hello.json")
    print(document.content)  # {'message': 'Hello, MarkLogic!'}
    ml.documents.delete("/hello.json")
```

The [documents guide](user/python/documents.md) covers XML, JSON, text, binary
content and metadata. Use [transactions](user/python/transactions.md) to group
related changes into one commit or rollback.

## Use REST, Manage, Admin and raw HTTP

The same client exposes MarkLogic's API tiers alongside higher-level services
such as `ml.documents` and `ml.eval`:

```python
with MLClient() as ml:
    query_response = ml.rest.eval.post(xquery='"Hello World!"')
    databases_response = ml.manage.databases.get_list()
    timestamp_response = ml.admin.get_timestamp()
    raw_response = ml.http.post("/v1/eval", {"xquery": '"Hello World!"'})
```

These calls return HTTPX responses, giving you access to status codes, headers
and response bodies. Use `ml.rest`, `ml.manage` and `ml.admin` for named endpoint
methods, or `ml.http` to control the method, path, parameters, headers and body
yourself.

The API wrappers use their corresponding connections (REST on port 8000, Manage
on 8002 and Admin on 8001 by default). `ml.http` uses the primary connection;
the URL path does not switch ports. Your account needs permission for each
operation. See [Clients](user/clients.md) for details.

## Use async

The asynchronous client exposes the same operations:

```python
import asyncio
from mlclient import AsyncMLClient


async def main():
    async with AsyncMLClient() as ml:
        print(await ml.eval.xquery('"Hello World!"'))


asyncio.run(main())
```

See [async support](user/python/async.md) for client reuse and concurrent requests.

## Use the command line

```sh
ml env init
ml eval -x '"Hello World!"'
ml logs
ml logs --all-hosts --regex 'Forest M.*'
ml version
```

Review the environment generated by `ml env init` before sending requests.
The [CLI guide](user/cli.md) covers importing Gradle settings, discovering servers
and running commands. To choose between parsed results, REST wrappers and raw
HTTP in Python, continue with [clients and API layers](user/clients.md).
